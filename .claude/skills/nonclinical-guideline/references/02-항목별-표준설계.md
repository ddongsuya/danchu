# 항목별 표준 설계 (의약품 · 일반독성)

동물 수·회복군·TK 같은 "통상 어떻게 하는지"를 묻는 질문에 답할 때 쓴다. 숫자는 식약처 「의약품등의 독성시험기준」과 ICH 기준의 최소값이며, 회복군 지정 방식·마릿수처럼 기관마다 다른 부분은 그렇게 적혀 있다. 그 부분은 값을 정해 주지 말고 "기관마다 다르다"고 답한다.

## 단회투여독성

적용 항목: 단회(급성)투여독성

한 번 투여했을 때의 독성 양상과 개략의 치사량을 봅니다.

| 설계 요소 | 통상 값 |
|---|---|
| 동물종 | 설치류 1종 + 비설치류 1종 (통상 랫드, 비글) |
| 동물 수 | 설치류 군당 암수 각 5마리 이상, 비설치류 암수 각 2마리 이상 |
| 용량 | 설치류는 용량 단계별 군 구성, 비설치류는 같은 동물에 용량을 올려 가는 용량증량법 |
| 관찰 | 투여 후 14일, 일반증상·체중·부검 |
| GLP | 허가 제출용이면 GLP |

근거: 식약처 「의약품등의 독성시험기준」 · ICH M3(R2), 다른 시험에서 급성 독성 정보를 얻었다면 생략 가능

표준 설계로 요청 시 채우는 값: species=랫드/개(비글), method=ICH M3 단회 설계, glpLevel=GLP, recovery=없음, tk=미포함

## 용량결정시험(DRF)

적용 항목: 용량결정(DRF) 1주, 용량결정(DRF) 2주, 용량결정(DRF) 4주

본시험의 고용량과 용량 간격을 정하기 위한 예비시험입니다.

| 설계 요소 | 통상 값 |
|---|---|
| 동물종 | 본시험과 같은 종·계통 |
| 동물 수 | 설치류 군당 암수 각 3~5마리, 비설치류 암수 각 1~2마리 수준 |
| 평가 | 일반증상·체중·사료섭취·임상병리·부검. 조직병리는 선택 |
| TK | 본시험 채혈 시점을 잡기 위해 소규모로 병행하기도 합니다 |
| GLP | 보통 Non-GLP |

근거: ICH M3(R2) · 식약처 「의약품등의 독성시험기준」 해설

표준 설계로 요청 시 채우는 값: glpLevel=Non-GLP, recovery=없음, histopath=미정, method=ICH M3/S4 반복투여

## 반복투여독성 (2~4주)

적용 항목: 반복투여 1주, 반복투여 2주, 반복투여 4주

초회 임상(1상)을 뒷받침하는 핵심 시험입니다. 표적 장기와 무독성량(NOAEL)을 확인합니다.

| 설계 요소 | 통상 값 |
|---|---|
| 동물종 | 설치류 1종 + 비설치류 1종 |
| 군 구성 | 대조군 + 3용량 이상 |
| 동물 수 | 설치류 군당 암수 각 10마리 이상, 비설치류 암수 각 3마리 이상 |
| 회복군 | 대조군과 고용량군에 둠. 회복 기간 2~4주. 회복 동물의 지정 방식과 마릿수는 기관마다 다름 |
| TK | 병행. 설치류는 위성군으로 채혈하는 경우가 많습니다 |
| 평가 | 일반증상, 체중, 사료섭취, 안과검사, 임상병리, 뇨검사, 부검, 장기중량, 조직병리(검경 포함) |
| GLP | GLP |

근거: 식약처 「의약품등의 독성시험기준」 · ICH M3(R2) · ICH S3A 독성동태

표준 설계로 요청 시 채우는 값: species=랫드/개(비글), recovery=2주, tk=포함, formulation=포함, histopath=포함, glpLevel=GLP, method=ICH M3/S4 반복투여

## 반복투여독성 (13주)

적용 항목: 반복투여 13주

3개월까지의 임상 또는 1개월 이내 의약품의 허가 신청을 뒷받침합니다.

| 설계 요소 | 통상 값 |
|---|---|
| 동물종 | 설치류 1종 + 비설치류 1종 |
| 군 구성 | 대조군 + 3용량 이상 |
| 동물 수 | 설치류 군당 암수 각 10마리 이상, 비설치류 암수 각 3~4마리 |
| 회복군 | 대조군과 고용량군에 둠. 회복 기간 4주가 일반적. 지정 방식은 기관마다 다름 |
| TK | 병행 (투여 첫날과 마지막 주) |
| GLP | GLP |

근거: 식약처 「의약품등의 독성시험기준」 · ICH M3(R2)

표준 설계로 요청 시 채우는 값: species=랫드/개(비글), recovery=4주, tk=포함, formulation=포함, histopath=포함, glpLevel=GLP, method=ICH M3/S4 반복투여

## 만성 반복투여독성 (26주 이상)

적용 항목: 반복투여 26주, 반복투여 39주, 반복투여 52주

6개월을 넘는 임상과 장기 투여 의약품의 허가 신청을 뒷받침합니다.

| 설계 요소 | 통상 값 |
|---|---|
| 기간 | 설치류 6개월(26주), 비설치류 9개월(39주)이 ICH 기준 |
| 동물 수 | 설치류 군당 암수 각 10마리 이상(중간 부검을 두면 추가), 비설치류 암수 각 4마리 수준 |
| 회복군 | 대조군과 고용량군에 둠. 지정 방식은 기관마다 다름 |
| TK | 병행 |
| GLP | GLP |

근거: ICH M3(R2) · ICH S4 만성독성시험 기간 · 식약처 「의약품등의 독성시험기준」

표준 설계로 요청 시 채우는 값: recovery=4주, tk=포함, formulation=포함, histopath=포함, glpLevel=GLP, method=ICH M3/S4 반복투여

## 용어

| 용어 | 뜻 |
|---|---|
| GLP | 비임상시험관리기준. 허가 자료로 쓰려면 GLP 인증 기관에서 GLP로 수행해야 합니다. |
| TK (독성동태) | 독성시험 동물의 혈중 약물 농도를 측정해 실제 노출량을 확인합니다. 사람 노출과 비교하는 근거가 됩니다. |
| 회복군 | 투여를 멈춘 뒤 독성 변화가 회복되는지 보기 위해 대조군과 고용량군에 두는 동물입니다. 지정 방식은 기관마다 다릅니다. |
| 위성군 | TK 채혈처럼 본시험 동물에 부담을 주는 조작을 따로 하기 위해 두는 추가 동물입니다. |
| NOAEL (무독성량) | 유해한 영향이 관찰되지 않은 최대 용량. 초회 임상 용량 산정의 출발점입니다. |
| DRF (용량결정시험) | 본시험의 용량을 정하기 위한 예비시험. 보통 Non-GLP입니다. |
| 조제물분석 | 동물에 투여한 조제물의 함량·균질성·안정성을 확인하는 분석. GLP 독성시험에 따라옵니다. |
| 조직병리 | 장기를 현미경으로 검사하는 평가. 단추 양식에서는 검경까지 포함을 기본으로 봅니다. |

참고용 안내입니다. 최종 시험 설계는 시험기관 및 규제기관 상담으로 확정하세요.
