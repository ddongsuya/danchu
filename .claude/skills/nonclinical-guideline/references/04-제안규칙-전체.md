## 기관에 확인할 것 (가이드라인이 정하지 않는 부분, 21)

- 용량결정시험의 구성과 본시험 견적 포함 여부
- 회복 동물의 지정 방식과 투여 종료 시·회복 종료 시 부검 동물 수
- 조직병리 확대 판독과 특수염색의 견적 포함 여부
- 독성동태의 채혈 방식(위성군·미량채혈), 시점 수, 예상 검체 수
- 유전독성의 용량 설정 예비시험·확인 시험 포함 여부
- 텔레메트리 동물 수와 설계(교차·병행), 노출 확인 포함 여부
- hERG 방식(수동·자동), 농도 수, 농도 검증 포함 여부
- 생체시료 분석법 검증의 종류(전체·부분)와 횟수, 종별 구분
- 조제물 분석법 검증 횟수와 구분 (체외 유전독성·체외 약리·체내 등 부형제별)
- 조제물분석의 허용 기준, 분석 횟수, 독성시험 금액 포함 여부
- 임신동물 확보 방식과 교배 시작 동물 수
- 생식독성 독성동태의 채혈 방식(본시험 동물·위성군)과 예상 검체 수
- 태자 검사 범위(전수·절반)와 용량설정시험의 견적 포함 여부
- 출생 전후 발생시험의 행동·기능 검사 항목과 방법
- 약물동태·체외 시험의 설계(동물 수, 시점, 농도)와 예상 검체 수, 분석법 검증 포함 여부
- 투여 부위 조직병리의 채취 방법과 견적 포함 여부
- 발육기동물시험의 새끼 확보·한배 배정 방법, 가능한 최소 투여 일령, 수행 가능한 추가 평가항목
- 항원성시험의 군 구성 (용량, 보조제 유무, 결합체 포함 여부)
- 자극·감작성 시험의 동물 수와 판정 기준
- 발암성시험의 동물 계통과 배경자료 보유 기간, 형질전환 마우스 시험의 표준 설계
- 흡입 노출 방식(비부·전신), 입자 크기 측정, 기관지폐포세척 포함 여부, 예상 시험물질 소요량
